# DeckBridge integrates deeper than Syndicate's MIDI mapping, and maps every control too

2026-11-17. The user's decision: DeckBridge's goal is deeper integration through Syndicate's OSC: LED and VU feedback, 14-bit controls, relative encoders, pickup, deck and Shift layers, and the jog display, none of which Syndicate's own MIDI mapping can do (User Guide 0.3.7, section 13.9). It also maps every control from MIDI to OSC, because that saves users mapping by hand and lets the controller and DeckBridge run on a different computer from Syndicate, with OSC over the network (#84). So profiles map controls fully, the full mixer stays (#207), and a feature is justified by deeper integration, less setup, or remote use (#191). Rejected: stripping DeckBridge back to only what Syndicate can't map.
